Daylight DC-1 workspace
---

This has some scripts, docs, and files for the daylight dc-1 <https://daylightcomputer.com>.

## Usage
- install [git xet](https://huggingface.co/docs/hub/xet/using-xet-storage)
- `git clone --recurse-submodules git@github.com:adiktofsugar/daylight.git`
- install [uv](https://docs.astral.sh/uv/)
- install Java JRE 11 (for jadx). I recommend doing this with [sdkman](https://sdkman.io).

## Scripts

All scripts are in bin, you should be able to execute them directly. You can also run `export bin/env.sh` to add to your path.

## Images

The images are on huggingface in <https://huggingface.co/datasets/anincrediblyshortname/daylight-dc-1-images>, which is the images submodule here. To actually download them via `git clone`, you need git xet installed <https://huggingface.co/docs/hub/xet/using-xet-storage>.
